# Maintenance Manual: Protection Relays

## Test intervals

Carry out a functional test of every protection relay every 4 years. Test the trip-circuit supervision once per year.

## Firmware

Install firmware updates only from an approved release list. After each update repeat the functional test of the affected protection functions.

## Records

Keep the test records of all protection relays for 10 years. Each record must include the settings file that was active during the test.
